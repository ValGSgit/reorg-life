# T-011 — Cut the placeholder sheets into per-mood transparent PNGs

## Goal

Sprout and Ember appear in the app as artwork instead of blobs during
development, so layout and mood switching can be judged against something
close to the real thing.

These stay **placeholders**. This task does not make anything shippable — see
T-010 for that.

## Acceptance criteria

- [ ] `assets/characters/sprout-{1..5}.png` and `ember-{1..5}.png`, transparent,
      about 512px
- [ ] Generated by a script in `scripts/`, so it is repeatable and reviewable
      rather than a one-off manual edit
- [ ] Raw sheets stay in `assets/characters/_raw/` and stay gitignored
- [ ] `docs/ASSETS.md` records that these are watermark-derived placeholders
      and must not ship
- [ ] `src/characterArt.ts` entries uncommented for Sprout and Ember only
- [ ] Dusk is **not** processed: its sheet has text baked in
- [ ] The blob fallback still works and is still tested

## Tests to write first

- [ ] Every path in `characterArt.ts` resolves
- [ ] Dusk still falls back to the blob — it is on the critical path for the
      time-of-day rotation
- [ ] Each generated file is actually transparent at its corners

## Files likely touched

```
scripts/process-character-sheets.mjs   (new)
assets/characters/*.png
src/characterArt.ts
docs/ASSETS.md
```

## Notes

Cutting a character out of a sheet does not itself carry the corner watermark.
That does **not** make the result shippable, and `docs/ASSETS.md` must keep
saying so. Do not retouch, paint over or crop **at** a watermark to disguise
provenance.

Mood order on the sheets runs left to right, rough to thriving.

## Blockers

None. Cut this freely — blobs are a perfectly good stand-in.
